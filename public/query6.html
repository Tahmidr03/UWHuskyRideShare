Query 6: Transaction Demo - Fund Transfer

Demonstrate database transactions using BEGIN, COMMIT, and ROLLBACK

Transfer Funds Between Accounts

Transfer funds between bank accounts. The transaction will rollback if there's insufficient balance or any error occurs, demonstrating atomic transaction processing.

💡 Note: There are 15 bank accounts available. Use the "View Available Accounts" button below to see all account IDs and balances before making a transfer. Try transferring more than the balance to see ROLLBACK in action.
Transaction Details

This transaction uses the following database operations:

  • BEGIN - Starts a transaction
  • SELECT ... FOR UPDATE - Locks accounts to prevent concurrent modifications
  • UPDATE - Deducts amount from source account
  • UPDATE - Adds amount to destination account
  • COMMIT - Commits the transaction if all checks pass
  • ROLLBACK - Rolls back all changes if any error occurs or validation fails
